# IOT BASED AUDIO TRANSFER USING LI-FI BY SMART LIGHTING SYSTEM

## Overview
This project uses Li-Fi technology to transfer audio signals through LED light. The system consists of a transmitter, receiver, LED light source, photodiode, and IoT-enabled monitoring.

## Components
- Arduino/ESP32
- LED
- Photodiode
- Audio Amplifier
- Speaker
- Power Supply

## Working
1. Audio signal is converted into digital data.
2. LED transmits data using light intensity variations.
3. Photodiode receives the light signal.
4. Signal is amplified and played through a speaker.

## Applications
- Smart Homes
- Hospitals
- Secure Communication
- Smart Lighting Systems
